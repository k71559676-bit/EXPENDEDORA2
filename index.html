PROYECTO ACADÉMICO · SENATI

No hay un lugar cercano donde comprar alimentos para los estudiantes de SENATI

Propuesta de una máquina expendedora pensada para facilitar el acceso rápido y práctico a productos de consumo durante la jornada académica.

Conocer el proyecto
EL PROYECTO

Escuchar para solucionar

Este proyecto nace a partir de las necesidades, experiencias y opiniones de los estudiantes de SENATI durante su jornada académica.

Nuestro objetivo es diseñar una máquina expendedora que permita acceder de manera rápida, sencilla y práctica a productos que los estudiantes puedan necesitar dentro de la institución.

01

Design Thinking

Utilizaremos las etapas de empatizar, definir, idear, prototipar y evaluar para desarrollar nuestra propuesta.
